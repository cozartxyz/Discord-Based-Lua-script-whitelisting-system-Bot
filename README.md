# Discord-Based-Lua-script-whitelisting-system-Bot
A JS Api based whitelist system

this is a whitelisting system i made for authentication on a lua based product. in theory this could just be altered slightly to use across things other than lua explicitly

---

## Features

- Key generation system
- User whitelist management
- HWID reset functionality
- Blacklist system
- Discord slash command integration
- MongoDB database support
- Lua loader authentication support
- Basic admin management workflows
